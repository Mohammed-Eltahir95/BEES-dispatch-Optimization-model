# Limitations

- The input prices and degradation curve lack citable source provenance.
- Only a 24-hour 10 MWh / 5 MW fixture is committed; no 100 MW case exists.
- Reserve-market rules are simplified and omit detailed activation, symmetry,
  duration, availability, bid-size, and settlement requirements.
- Forecasting from one day of fixture data cannot establish predictive skill.
- The degradation curve is loaded by utilities but is not used in the objective;
  dispatch uses a constant throughput cost instead.
- No uncertainty, scenario comparison, out-of-sample forecast validation,
  measured-data calibration, or runtime benchmark is committed.
- Financial units, taxes, fees, network constraints, and asset availability are
  `[TO BE COMPLETED]` for any operational interpretation.
