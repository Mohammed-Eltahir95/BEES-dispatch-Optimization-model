# Results policy

Generated outputs are intentionally ignored. A scientific release should archive
the exact configuration, input checksums, environment lock/export, solver log,
termination condition, CSV tables, and figures for each reported result.

No committed result currently supports claims of 13% revenue improvement, 14%
cycle reduction, validation deviation below 1.5%, or a runtime change from 23 to
8 minutes. These values must not be quoted as repository-verified outcomes.
